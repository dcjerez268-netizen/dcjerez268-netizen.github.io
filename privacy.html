Nagatha – Privacy Policy

Last updated: October 3, 2026

Nagatha is a personal assistant app used only by its owner, Debbie Jerez. It is not available to the public.

What data Nagatha accesses

With the owner's permission through Google sign-in, Nagatha can read the owner's Google Calendar events and Gmail messages.

How the data is used

This data is used only to provide assistant features to the owner, such as summarizing her schedule and email. It is not used for advertising, is not sold, and is not shared with anyone else.

Where the data is stored

Data is processed on the owner's own computer. Access can be removed at any time at myaccount.google.com/permissions.

Google API Services

Nagatha's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
